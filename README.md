# OnlyBoosts

An expanded, standalone version of the podcast-boost feed that started on
[localbitcoiners.com](https://localbitcoiners.com). Where the Local Bitcoiners
feed shows boosts for one show, OnlyBoosts aims to be a broader home for
Podcasting 2.0 / V4V boost activity across the Nostr + Lightning ecosystem.

## Layout

- **`bots/`** — automated collectors and publishers (Nostr / Lightning),
  following the same patterns as the Local Bitcoiners bot suite.
- (website / frontend to come)
